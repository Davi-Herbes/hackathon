# Hackathon - IFRS Campus Feliz - 2024
Participantes: **Davi de Matos, João Luft, Felipe Paz, Lucas Flach, Arthur Lassem**

Este é o repositório do projeto que foi cointruído durante a hackathon, usando ReactJS, Typescript, Vite.
---

O tema que nos foi dado se tratava dos desastres climáticos que abalaram o Rio Grande do Sul nos últimos meses, então resolvemos fazer uma interface gráfica que mostrava como o aplicativo funcionaria, sendo um ponto central para auxílios em situações de emergência, contendo dicas, chamadas de emergência, solicitações de resgate, mapas informando localidades com maior risco, etc. O Consumo de APIs e dados externos se viu como impossível por conta do tempo que tivemos e por só saber do assunto na hora, então fizemos apenas o frontend.
